Purpose

Siedler Österreich is a non-commercial browser game in alpha stage. It serves the playful exploration of public Austrian cadastre data, raises awareness for nature conservation and biodiversity, and demonstrates data processing methods.

Source code

The source code of this project is openly available on GitHub.

Data sources and licences

The map display is based on open data. Every source is fetched server-side; the browser never talks to the data providers. Cadastre (parcels, building footprints, land-use areas): © BEV – Federal Office of Metrology and Surveying, cadastral map as vector tiles from kataster.bev.gv.at, licensed CC BY 4.0. Mandatory notice: “© BEV, 2026 – Datenquelle: Bundesamt für Eich- und Vermessungswesen, Kataster (CC BY 4.0), bearbeitet”.

Legal basis: product description “Katastralmappe VTC” (BEV_S_KA_Katastralmappe_VTC.pdf) section 2.3 Licence: “The standard licence Creative Commons CC BY 4.0 applies to the products described here” – the tileset https://kataster.bev.gv.at/at.gv.bev.kataster/tiles/{kataster|symbole}/{z}/{x}/{y}.pbf is that product. CC BY 4.0 section 4 explicitly grants the sui generis database right (§§ 76c–76e Austrian Copyright Act) as well. We use neither the paid DKM (BEV terms of use, Amtsblatt 3/2022) nor the Katasterservice (search / information API). The tiles are assembled into parcels by a service of our own whose source code is open (MIT): github.com/raffopenssh/vtcseamless (preset bevdirect, version v0.3.0). Assembled grid cells and tiles are cached for at most 24 h and pruned continuously. Parcels and folios (EZ) can only be found inside a visible map extent, never without a location; the tiles contain no owner data. BEV note: no legally binding coordinates can be derived from the tiles – the game is not an official register extract. Every rendering carries the notice “© BEV, 2026 … CC BY 4.0, bearbeitet”.

Further sources: BEV administrative boundaries (VGD), BEV ALS DTM/DSM 1 m & orthophoto (CC BY 4.0, modified), Copernicus Sentinel 2022–2025 (EU/ESA), ESA WorldCover 2021, Statistics Austria, EEA Natura 2000, WDPA (UNEP-WCMC & IUCN, non-commercial), European Red List (IUCN/EEA), OpenStreetMap (ODbL), BEV DLM geographic names (as of 2025-03-25), RIS, AMA INVEKOS, Hansen/GFW GFC 2000–2024 v1.12, BML eHYD, MERIT Hydro, geoBoundaries.
