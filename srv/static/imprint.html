Purpose

Siedler Österreich is a non-commercial browser game in alpha stage. It serves the playful exploration of public Austrian cadastre data, raises awareness for nature conservation and biodiversity, and demonstrates data processing methods.

Source code

The source code of this project is openly available on GitHub.

Data sources

The map display is based on open data, including the Austrian cadastre (BEV – Federal Office of Metrology and Surveying), OpenStreetMap, and open geo and remote-sensing data. The in-game presentation is simplified and playfully altered; it is not an official statement and has no legal effect whatsoever.
